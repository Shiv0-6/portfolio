## ⚡ Quick Reference

### To Enable Dark Mode
Click the moon icon (🌙) in the top-right corner.

### To Change Colors
Open `assets/css/main.css` and find `--accent-color: #149ddd;` and change the hex code.

### To Speed Up Animations
Find `transition:` properties and change the duration (e.g., `0.3s` to `0.1s`).

### To Disable a Feature
Open `assets/js/main.js` and comment out the feature function (add `//` at beginning).

### To Test Everything
Follow the detailed steps in [TESTING_GUIDE.md](TESTING_GUIDE.md).
