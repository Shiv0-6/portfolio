## 🎨 Customization Examples

### Change Brand Color
```
Open: assets/css/main.css (line ~30)
Find: --accent-color: #149ddd;
Change #149ddd to your color
Example: #e74c3c (red), #27ae60 (green)
```

### Speed Up Animations
```
Find: transition: all 0.3s ease;
Change 0.3s to 0.1s for faster
Change 0.6s to 0.3s for faster
Refresh page to see changes
```

### Disable Parallax
```
Open: assets/js/main.js
Find: initParallaxEffect();
Comment out: // initParallaxEffect();
Refresh page
```
